# K-Drift (케이드리프트) — 서비스 소개서

> 한국 거주 외국인을 위한 **다국어 생활·경제·법령정보 마스터 뉴스레터 & 정보 큐레이션 플랫폼**
> _비즈니스 파트너·투자사용 · 2026.06_

---

## 0. 한 줄 정의

**"외국인이 한국어 없이도, 신뢰할 수 있는 한국 생활·법령 정보를 모국어로 받아본다."**

K-Drift는 비자·의료·주거·노동·교육·세금 등 한국 생활의 핵심 정보를 **베트남어·영어·한국어**로 큐레이션해 전달하는 뉴스레터에서 출발해, **정보 포털 → 생활서비스 제휴**로 확장하는 플랫폼입니다.

핵심 차별점은 콘텐츠를 사람이 일일이 만드는 게 아니라, **AI 에이전트가 정부·법령 채널에서 정기 수집 → 외국인 친화적으로 요약·큐레이션 → 사람이 최종 검증·승인 → 자동 다국어 번역·발행**하는 **반자동 콘텐츠 엔진**을 갖췄다는 점입니다.

---

## 1. 문제 (Problem)

한국 거주 외국인은 빠르게 늘지만, **그들이 믿고 의지할 모국어 정보 창구가 없습니다.**

- 비자 연장, 건강보험 가입, 전세 사기 예방, 임금체불 대응, 연말정산 — 모두 **한국어 행정 용어**로 되어 있어 접근 장벽이 높습니다.
- 정보가 **여러 정부 부처에 흩어져** 있고, 외국인 관점으로 정리된 곳이 거의 없습니다.
- 부정확한 카페·블로그·지인 정보에 의존하다 **실제 피해**(보증금 손실, 체류 자격 문제, 세금 불이익)로 이어집니다.

> **시장 근거 (자사 기획 기준):** 국내 거주 외국인 약 **270만 명(2025)**, 그중 **베트남인 약 33만 명**으로 단일 최대 집단. 자체 설문 **3,813명 중 91%가 "믿을 만한 정보 플랫폼이 없다"** 고 응답.

---

## 2. 타깃 & 언어

- **1차 페르소나:** 한국 거주 1~3년차 **베트남인**(20~30대, 노동/유학 비자), 모바일 우선.
- **노출 언어:** 베트남어(기본) · 영어 · 한국어. 콘텐츠는 **한국어 원천(1차 출처)으로 작성·검증 후 자동 번역**.
- 확장 언어(중국어·태국어 등)는 동일 구조로 추가 가능하도록 설계.

---

## 3. 정보 구조 (5+ 카테고리)

| 카테고리 | 다루는 정보 |
|---|---|
| **비자·체류** | 비자 종류·연장, 외국인등록증, 영주권 |
| **의료·건강보험** | 건강보험 가입, 병원 이용, 응급 |
| **주거·부동산** | 전·월세 계약, 보증금, 사기 예방 |
| **노동·취업** | 근로계약, 임금체불 대응, 4대보험 |
| **교육·생활** | 한국어, 은행·통신 개통, 행정 |

세금·경제 등 카테고리는 동일 구조로 확장 가능.

## 4. 솔루션 — K-Drift는 무엇인가

K-Drift는 **두 개의 얼굴**을 가진 플랫폼입니다.

**(A) 독자(외국인)가 보는 것 — 신뢰 가능한 다국어 생활정보**
- 모국어 뉴스레터로 핵심 정보를 정기 수신
- 웹사이트에서 카테고리·검색으로 글을 탐색, 언어를 자유롭게 전환

**(B) 운영자가 보는 것 — AI 콘텐츠 엔진 (핵심 경쟁력)**
- 정부·법령 채널을 정기 수집하고, AI가 외국인 관점으로 요약·큐레이션
- 사람은 **검증·승인만** 하면, 자동으로 다국어 번역·발행

즉, **소수 인력으로 다국어 콘텐츠를 대량·정확하게 생산**하는 구조가 K-Drift의 해자(moat)입니다.

## 5. 실제 구현된 것 (Product — Built)

> 아래는 **현재 동작하는 MVP에 실제 구현된 기능**입니다. (로드맵 항목은 9장에 별도 구분)

### 5-1. 다국어 공개 플랫폼
- **3개 언어(vi/en/ko)** 전체 라우팅, 언어별 콘텐츠 + **누락 시 자동 대체**(ko→en→vi)
- **랜딩 페이지**: 히어로·구독폼·소셜프루프·카테고리·후기·CTA
- **글 목록/상세**: 카테고리 필터 + 검색, 목차(TOC), 언어 토글, 커버 이미지
- **뉴스레터 아카이브**: 지난 호 목록·상세
- **구독 처리**: 이메일 구독 → 데이터베이스 저장 + **환영 메일 자동 발송**

### 5-2. 관리자 시스템 (인증 기반)
- **글 에디터**: vi/en/ko 탭, **Markdown 실시간 미리보기**, **이미지·커버 업로드**(클라우드 스토리지), **슬러그 자동 생성**, 저장 후 이어쓰기
- **뉴스레터 작성·발송**: 발행 글을 모아 호 구성 → **대량 발송**(이메일 서비스 연동) → 발송 기록 보관

### 5-3. AI 자동 번역 ⭐
- **한국어 원문 작성 → 버튼 한 번으로 영어·베트남어 자동 생성**
- 최신 AI 모델 기반, **Markdown 구조·고유명사(한국어 병기)·톤 보존**
- 자동번역은 **검토·수정 후 발행**(사람 확인 단계 유지)

### 5-4. AI 콘텐츠 수집·큐레이션 파이프라인 ⭐⭐ (핵심)
정부·법령 채널 → AI 초안 → 사람 승인 → 글·뉴스레터로 이어지는 **반자동 엔진**:

```
① 수집      정부 채널(법무부·고용노동부·정부 보도자료 등 공식 피드) 자동 수집 + 수동 입력
② AI 큐레이션  외국인 관련성 판정 → 친화적 요약 + "외국인에게 의미" + 시행일 + 신뢰도 점수
③ 검토 큐    사람이 승인 / 수정 / 반려  ← 신뢰의 핵심 게이트
④ 자동 승급   승인 시 → 한국어 글 초안 자동 생성
⑤ 번역·발행   자동 번역(5-3) → 검토 → 발행 → 뉴스레터
```
- **AI가 90%를 차려놓고, 사람은 마지막 승인만** — 법령·생활정보 특성상 **사람 검증을 필수**로 설계.
- 관련 없는 정보(인사발령·내부행사 등)는 AI가 **자동으로 걸러냄**.
- 각 항목에 **출처 링크·신뢰도 점수**를 부여해 검증 가능성 확보.

## 6. 사용법 (How to Use)

### 6-1. 독자(외국인) 관점
1. 랜딩 페이지에서 **이메일 구독** (모국어 선택)
2. 모국어 **뉴스레터**로 정기적으로 핵심 생활정보 수신
3. 필요 시 웹사이트에서 **카테고리·검색**으로 원하는 정보 탐색, **언어 전환**으로 비교

### 6-2. 운영자 관점 (콘텐츠 1건 생산 흐름)
1. **수집·큐레이션** 화면에서 정부 채널 "수집" 클릭 (또는 법령 본문 붙여넣기)
2. 수집 항목에 **"AI 요약"** → 외국인 친화 초안 자동 생성
3. **검토 큐**에서 신뢰도·출처 확인 후 **승인** → 한국어 글 초안 자동 생성
4. 에디터에서 **"한국어 → 자동번역"** → vi/en 자동 완성, 다듬기
5. **발행** → 뉴스레터 호에 담아 발송

> 기존에는 1건당 *수집·번역·작성*에 상당한 인력·시간이 들던 작업을, **클릭 몇 번 + 검증**으로 압축합니다.

## 7. 효과 & 가치 (Why it matters)

**독자에게**
- 언어 장벽 없이 **신뢰 가능한 1차 출처 기반** 정보 → 실제 피해 예방
- 흩어진 정부 정보를 **한곳에서, 모국어로**

**운영(사업)에게**
- **인력 대비 콘텐츠 생산성**이 비약적으로 높음 (AI 수집·요약·번역 자동화)
- **다국어 확장 비용이 낮음** (번역 자동화 + 동일 파이프라인 재사용)
- 콘텐츠가 쌓일수록 **검색 유입·구독 전환**이 누적되는 자산화 구조

**파트너에게**
- 신뢰 기반으로 모인 **명확한 타깃(거주 외국인) 오디언스**
- 생활서비스(통신·금융·부동산·법률·교육) **제휴·광고·리드 제공** 채널

| 단계 | 내용 | 수익화 |
|---|---|---|
| **1단계 (현재)** | 다국어 뉴스레터로 **신뢰·구독자 확보** | — (오디언스 구축) |
| **2단계** | 정보 큐레이션 **포털**로 확장, 회원·커뮤니티 | 광고·제휴 리드, 프리미엄 |

## 9. 현재 상태 & 로드맵 (정직한 구분)

**✅ 구현 완료 (동작하는 MVP)**
- 다국어 공개 사이트(랜딩·글·뉴스레터 아카이브)
- 구독 + 환영 메일
- 관리자(글 에디터·뉴스레터 발송)
- **AI 자동 번역**(한→vi/en)
- **AI 수집·큐레이션 파이프라인**(정부 채널 수집 → AI 초안 → 사람 승인 → 글 승급)

**🔜 로드맵 (다음 단계)**
- 수집 **자동 스케줄링**(정기 무인 수집)
- **출처 전문 대조 + 반박형 AI 검증**(정확도 강화)
- 뉴스레터 **블록 에디터**(리치 편집) + 예약 발송
- 수신거부·더블옵트인 등 **이메일 컴플라이언스**
- 회원/커뮤니티 · 프리미엄 · B2B 제휴 모듈(2·3단계)

## 10. 기술 개요 (참고)

- **프론트/백엔드:** Next.js 16 · React 19 · TypeScript · Tailwind
- **데이터/인증/스토리지:** Supabase (Postgres + Auth + Storage, 행 수준 보안)
- **이메일 발송:** Resend (구독 환영·뉴스레터 발송)
- **AI:** 최신 대규모 언어모델 API (번역·큐레이션·관련성 판정·요약, 구조화 출력 기반)
- **콘텐츠 출처:** 정부 공식 피드(법무부·고용노동부·정부 보도자료 등) + 국가법령정보 등 1차 출처 우선

> 신뢰 설계 원칙: **1차 출처 우선 · 출처·시행일·신뢰도 기록 · 사람 최종 승인 · 자동 발행 지양.**

## 11. 요약 (One-page takeaway)

- **시장:** 거주 외국인 270만, 91%가 "믿을 정보 없음" → 명확한 페인포인트
- **제품:** 다국어 생활·법령 뉴스레터 + **AI 콘텐츠 엔진**(수집→큐레이션→검증→번역→발행)
- **차별점:** 소수 인력으로 **다국어 콘텐츠 대량·정확 생산** (해자)
- **현황:** MVP 동작 — 공개 사이트·구독·관리자·AI 번역·AI 큐레이션 파이프라인 **구현 완료**
- **확장:** 뉴스레터 → 포털 → 생활서비스 제휴 (3단계 수익화)
